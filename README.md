Python Data Analysis 

A practical project focused on learning and applying Python for Data Analysis, from programming fundamentals to working with real-world datasets.

Overview

This project covers the essential stages of working with data in Python, including data manipulation, cleaning, exploration, and preparation for analysis.

Key Areas

Python Fundamentals — Variables, data types, lists, dictionaries, indexing, and basic operations.

NumPy — Arrays and numerical operations.

Pandas — DataFrames, filtering, selection, and data manipulation.

Data Cleaning — Missing values, duplicates, data types, and quality checks.

Data Exploration — Understanding dataset structure and generating statistical summaries.

Practical Analysis — Applying Python to Supermarket and Employee Attrition datasets.


 Tools & Technologies

Python • Pandas • NumPy • Jupyter Notebook

Objective

To develop practical Python Data Analysis skills and learn how to transform raw data into clean, structured, and analysis-ready information.
